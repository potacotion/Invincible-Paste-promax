# 无敌粘贴大法 ProMax (Invincible Paste ProMax)

🚀 **一个旨在绕过各种粘贴限制、实现跨虚拟机（VM）高效粘贴的开源工具。**

## 📖 项目简介

在许多特定的软件环境（如金融终端、远程桌面、虚拟机、考试系统等）中，常规的 `Ctrl+V` 粘贴功能往往会被禁用或限制。此外，在去虚拟化的虚拟机（Hardened VM）中，由于禁用了虚拟机工具（如 VMware Tools 或 VirtualBox Guest Additions），物理机与虚拟机之间的剪贴板共享往往失效。

**无敌粘贴大法 ProMax** 正是为了解决这些痛点而生。它通过模拟底层键盘输入的方式，将文本“打”入目标窗口，从而完美绕过几乎所有的粘贴限制，并提供了一种新颖的跨虚拟机通信方案。

---

## ✨ 核心特性

- 🛡️ **绕过粘贴限制**：通过模拟键盘按键（Simulation）而非剪贴板 API，让目标软件以为是人工输入。
- 🌐 **跨虚拟机（VM）穿透**：配合虚拟机内的接收端，无需开启 VMTools 即可实现从物理机到虚拟机的文本传递。
- ⚙️ **低延迟驱动（高级模式）**：集成 `Interception` 驱动，支持更底层的按键模拟，稳定性更高。
- ⌨️ **自定义打字参数**：支持设置打字间隔、随机延时（模拟真人输入）、触发延时等。
- 🖱️ **全局热键控制**：默认 `F8` 开始，`F9` 停止，方便在任意窗口操作。
- 📋 **双输入模式**：支持直接读取剪贴板内容，或在软件内手动输入/粘贴待发送文本。

## 🛠️ 安装与要求

### 环境要求
- Windows 10/11
- Python 3.8+ (如果从源码运行)

### 源码运行安装依赖
```bash
pip install -r requirements.txt
```

### 依赖库说明
- `PyQt5`: 图形界面支持。
- `keyboard` / `pynput`: 常规模式下的按键模拟与热键监听。
- `pyperclip`: 剪贴板读取。
- `interception-python`: 高级模式下的底层驱动调用。

## 🚀 使用指南

### 1. 常规模式 (模拟打字)
适用于大多数被禁用粘贴功能的常规软件（如网页表单、某些客户端等）。
1. 运行 `promax_app.py`。
2. 在界面中选择“剪贴板模式”或“输入模式”。
3. 设置合适的“打字间隔”（如需模拟真人，建议开启“随机间隔”）。
4. 点击“应用热键”（默认 F8）。
5. 切换到目标输入框，按下 **F8**。
6. 程序将开始模拟输入，如需中断请按 **F9**。

### 2. 高级模式 (虚拟机穿透)
适用于去虚拟化、禁用 VMTools 或常规模拟无效的环境。

#### 第一步：安装 Interception 驱动
1. 在主界面点击“下载并安装驱动”。
2. 程序会自动下载并运行驱动安装器。
3. **安装完成后必须重启计算机**，驱动才会生效。

#### 第二步：配置虚拟机接收端
1. 将 `vm_receiver_app.py` 复制到虚拟机内并运行（建议使用 `pythonw` 运行以隐藏窗口）。
2. 接收端会自动监听特定的特征序列。
3. （可选）接收端支持 `--install` 参数注册为开机自启动。

#### 第三步：开始传输
1. 在物理机上勾选“启用高级输入模式”。
2. 在目标虚拟机窗口内点击激活输入框。
3. 按下 **F8**。
4. 物理机程序会将文本转换为 HEX 特征码并快速“输入”到虚拟机。
5. 虚拟机内的接收端捕获到特征码后，会自动将其还原并再次模拟打字输入到虚拟机内的当前窗口。

## ⚙️ 详细配置项

| 配置项 | 说明 |
| :--- | :--- |
| **打字间隔** | 每个字符输入之间的等待时间（秒）。 |
| **随机间隔** | 在设定间隔的基础上增加 ±50% 的波动，模拟人类打字节奏。 |
| **触发延时** | 按下 F8 后等待多久开始输入，留出切换窗口的时间。 |
| **触发/停止键** | 自定义全局快捷键。 |
| **高级模式** | 使用 Interception 驱动进行 HEX 编码传输，配合接收端使用。 |
